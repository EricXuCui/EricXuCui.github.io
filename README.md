## Current Work — Decision Scheduling for RL Game Agents

I am currently extending the Combat Learning Agent project to explore how real-time reinforcement learning agents decide **when to make their next policy decision**.

Different gameplay actions have different durations. For example, a dodge, light attack, or heavy attack may require different amounts of time before another decision is meaningful.

I am experimenting with action-dependent decision timing and interruption-aware scheduling to study how these mechanisms affect agent behavior and training.

This work is currently in development.
